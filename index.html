📱 Cài Đặt & Đóng Gói Ứng Dụng OMR Pro 2026 Trên Android
MÔI TRƯỜNG HIỆN TẠI: Đang kiểm tra...
Cách 1: Biên dịch file cài đặt .APK tự động qua GitHub Actions (Không cần cài Android Studio)

1. Giải nén file gói dự án OMR_Pro_2026_Android_Package.zip đi kèm.
2. Tải toàn bộ thư mục lên một kho lưu trữ (Repository) trên GitHub.
3. Mở tab Actions trên GitHub → Quy trình Build OMR Pro 2026 Android APK sẽ tự động chạy và xuất ra file OMR-Pro-2026-debug.apk sau ~2 phút để tải thẳng về điện thoại Android!

Cách 2: Xuất file .APK trực tiếp bằng Android Studio hoặc Script 1-Click

1. Mở thư mục dự án trong Android Studio (hoặc chạy build_apk.bat trên Windows / ./build_apk.sh trên macOS/Linux).
2. Chọn menu Build → Build Bundle(s) / APK(s) → Build APK(s).
3. Dự án đã tích hợp sẵn AndroidBridge Native: tự động cấp quyền Camera sau để quét phiếu OMR, hỗ trợ chọn file Excel danh sách học sinh, lưu ảnh bài chấm .JPG, gói .ZIP và bảng điểm .XLSX vào thư mục Downloads/OMR_Pro_2026 cũng như chia sẻ trực tiếp qua Zalo.

Cách 3: Cài đặt trực tiếp dạng WebAPK (PWA) ngay trên trình duyệt Chrome Android

Mở ứng dụng này bằng Google Chrome trên điện thoại Android → Bấm biểu tượng menu ⋮ (3 chấm góc phải) → Chọn "Thêm vào màn hình chính" (Add to Home screen / Cài đặt ứng dụng). Ứng dụng sẽ chạy toàn màn hình với biểu tượng riêng như một App gốc.

🍎 Cài Đặt & Đóng Gói Ứng Dụng OMR Pro 2026 Trên iPhone (iOS)
TRẠNG THÁI THIẾT BỊ APPLE / iOS: Đang kiểm tra...
Cách 1: Cài trực tiếp lên Màn hình chính iPhone trong 10 giây (Không cần máy tính / Không cần Jailbreak)

1. Mở ứng dụng này bằng trình duyệt Safari trên điện thoại iPhone.
2. Bấm vào nút Chia sẻ (Share - biểu tượng ô vuông có mũi tên hướng lên ⬆️) ở thanh công cụ dưới đáy màn hình Safari.
3. Kéo xuống và chọn "Thêm vào MH chính" (Add to Home Screen ➕) → Bấm Thêm (Add) ở góc phải trên cùng.
4. Ứng dụng OMR Pro 2026 sẽ xuất hiện ngoài màn hình chính iPhone với biểu tượng riêng, chạy toàn màn hình (hỗ trợ Dynamic Island / Tai thỏ), mở Camera sau quét phiếu siêu mượt và lưu ảnh chấm vào Thư viện Ảnh / Tệp (Files)!

Cách 2: Tự động biên dịch file .IPA trên đám mây bằng GitHub Actions (Không cần máy Mac)

1. Giải nén gói OMR_Pro_2026_iOS_iPhone_Package.zip và tải lên một kho lưu trữ GitHub.
2. Vào tab Actions → Chạy workflow Build OMR Pro 2026 iOS IPA (chạy trên máy chủ macos-latest của GitHub).
3. Tải file OMR-Pro-2026-iOS.ipa vừa xuất ra và cài vào iPhone thông qua Sideloadly, AltStore (miễn phí bằng tài khoản Apple ID cá nhân) hoặc TrollStore / ESign.

Cách 3: Biên dịch và cài trực tiếp từ Xcode trên máy Mac (OMRPro2026.xcodeproj)

1. Mở file OMRPro2026.xcodeproj trong gói giải nén bằng phần mềm Xcode.
2. Cắm cáp iPhone vào máy Mac, chọn tài khoản Apple ID tại mục Signing & Capabilities → Team và bấm nút Run (▶).
3. Dự án đã tích hợp sẵn cầu nối Swift WKWebView Native (iOSBridge): tự động duyệt quyền Camera sau trên iOS 15–18+, lưu ảnh trực tiếp vào Photos (Альбом ảnh iPhone), xuất file Excel/ZIP vào ứng dụng Tệp (Files → On My iPhone), hỗ trợ in phiếu qua AirPrint và gửi ảnh bài chấm qua Zalo / AirDrop.
